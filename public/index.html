🤖 Model Context Protocol (MCP) Server Active & Ready

This Jira application includes native MCP server support. AI agents like Claude Desktop, Antigravity, and Cursor can list projects, query issues, create tickets, transition statuses, and post comments autonomously!

1. Connect Claude Desktop / Antigravity

Add this to your MCP configuration file (e.g. claude_desktop_config.json): 

{
  "mcpServers": {
    "jira-clone": {
      "command": "node",
      "args": ["/Users/bharath/Desktop/jiraClon/server/mcp/stdio.js"]
    }
  }
}

2. HTTP & SSE Endpoints

  • Tools Schema: GET /api/mcp/tools
  • JSON-RPC 2.0: POST /api/mcp/rpc
  • SSE Stream: GET /api/mcp/sse
